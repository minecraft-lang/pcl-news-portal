使用文档

从安装到自定义的完整说明。全文约 6 分钟可读完。

概览

本项目把 Minecraft 官方资讯渲染成 PCL2 / PCL CE 启动器可以直接加载的主页片段。核心是一个文件：Custom.xaml。它由本地脚本 gen_pcl_homepage.py 抓取官方接口后生成；启动器加载它时不发任何网络请求，联网只发生在脚本抓取数据那一步。

依赖说明：运行时零依赖——PCL 侧纯静态、不联网，不加载任何第三方库或组件；但生成与刷新数据需要本机安装 Python 3（脚本只用标准库，无需 pip install 任何东西）。
关键认知：Custom.xaml 不是完整 XAML 文档，而是内嵌片段，没有 XML 声明、没有根元素、没有命名空间前缀，由启动器自动包容器。

安装

  1. 从首页下载取得 PCL-Homepage-Setup-1.0.0.exe。
  2. 双击运行。第一屏选择安装语言（简体中文 / English）。
  3. 选择"为所有用户安装"或"仅为我安装"。前者需要管理员权限，快捷方式写入公共目录。
  4. 确认安装路径，默认 D:\pcl主页，可自行修改。
  5. 完成后默认勾选"打开项目文件夹"，点完成即跳到安装目录。
; 安装后目录结构
D:\pcl主页\
  ├─ Custom.xaml           # 启动器加载的主页片段
  ├─ gen_pcl_homepage.py   # 抓取并生成 XAML 的脚本
  ├─ README.md             # 项目说明
  └─ 更新数据.bat           # 一键刷新入口

接着在 PCL 中打开 设置 → 个性化 → 主页，把主页文件指向该目录下的 Custom.xaml。部分版本需在"联网更新"里填写本地路径或直链，按界面提示操作即可。

页面构成

主页从上到下共七个区块，顺序固定，都是独立卡片：

区块说明
顶部提示条展示数据更新时间，并提供"刷新主页"按钮
版本速览正式版与最新快照双栏，含版本号与发布日期
最新新闻官方新闻列表，默认 8 条，点击标题打开网页
正式版更新日志最近 6 条正式版补丁摘要
快照更新日志最近 8 条快照摘要，默认折叠
快捷入口5 个按钮：新闻首页、中文 Wiki、下载页等
关于本主页数据来源与生成方式说明，默认折叠

文件说明

文件大小作用
Custom.xaml约 11 KB生成产物，启动器实际加载的主页片段
gen_pcl_homepage.py约 22 KB抓取官方数据、拼装 XAML、双位置写入

更新方式

只有一条路径：双击 更新数据.bat 跑一次。脚本会重新抓取官方数据并覆写 Custom.xaml。这一步需要本机有 Python 3（启动器读取主页这一步不需要）。

双击 更新数据.bat

双击安装目录里的 更新数据.bat。脚本会先探测可用的 Python 解释器（python 或 py -3），再执行生成逻辑，一次写入工程目录与启动器实际加载目录。窗口出现成功提示后，回到启动器点"刷新主页"。

双击 更新数据.bat
→ 等待窗口提示生成成功
→ 启动器主页点「刷新主页」
说明：不做定时任务、不联网拉取已生成的主页——内容何时更新完全由你决定，跑一次即刷新一次。若需要显式指定输出路径或使用离线数据，可直接调用生成器，参数见「命令行参数」。

命令行参数

参数作用
--out <path>指定输出文件路径，覆盖默认输出位置
--translations <json>传入外部翻译映射文件，用于本地化标题
--java-only只抓取 Java 版内容，跳过其他平台条目
--offline <dir>从本地目录读取缓存的官方 JSON，不联网

离线模式适合网络不稳定时复现问题：先把三个官方 JSON 下载到同一目录，再用 --offline 指向它。

双位置同步

脚本内维护一份同步目标列表：一次生成会同时写入桌面工程目录与启动器实际加载目录，避免"改了工程、启动器没变"的错位。

SYNC_TARGETS = [
    r"D:\pcl ce\PCL\Custom.xaml",
    r"C:\Users\Administrator\Desktop\pcl主页\Custom.xaml",
]

如果你的启动器装在别处，改这一处即可；只保留一项也能正常工作。

改配色

配色不要写死十六进制。用启动器的动态资源引用，换主题或换强调色时主页会自动跟随。

<!-- 主文字 / 次要灰 / 分隔线 -->
<SolidColorBrush x:Key="BR1"
  Color="{DynamicResource ColorBrush1}" />
<SolidColorBrush x:Key="BR4"
  Color="{DynamicResource ColorBrush4}" />
<SolidColorBrush x:Key="BR5"
  Color="{DynamicResource ColorBrush5}" />

改标题与文案

要替换卡片标题、按钮文字，直接编辑 Custom.xaml 中对应文本即可；批量改名请改脚本里的模板字符串，再重新生成，否则下次刷新会被覆盖。

顺序很重要：先生成、后手工微调可以，但一旦再次运行脚本，手工改动会被新的生成结果覆盖。长期有效的修改应该落在脚本里。

XAML 格式规范

生成脚本自带自检，下列任一条不满足都会报错退出：

  • 不允许出现 <?xml 声明——这是片段，不是文档。
  • 不允许出现默认命名空间声明（xmlns=）。
  • 不允许出现 xmlns: 前缀声明，local 由启动器注入。
  • 不允许出现"翻译施工中"字样。
  • MyCard 等标签必须成对闭合。

交互写法

不使用 WPF 的 Click，改用启动器事件：

<!-- 打开网页 -->
EventType="打开网页"  EventData="https://www.minecraft.net/en-us/news"

<!-- 刷新主页 -->
EventType="刷新主页"

<!-- 跳启动器内部页：必须是枚举名，不能填 URL -->
EventType="切换页面"  EventData="Download|DownloadInstall"

卡片留白

MyCard 标题栏浮于内容之上，内容容器必须留出上边距，默认 Margin="12,40,12,14"；字号或缩放更大时调整到 44 或 48。

数据源

接口提供内容
launchermeta.mojang.com/mc/game/
version_manifest_v2.json		版本号、发布状态与发布时间
launchercontent.mojang.com/v2/
javaPatchNotes.json		Java 版更新日志
launchercontent.mojang.com/v2/
news.json		官方新闻条目

三个接口均为公开只读，与官方启动器同源。抓取失败时脚本会保留上一版 Custom.xaml 不动，不会写出一份半成品。

问题排查

主页一片空白，或加载报错

先确认 Custom.xaml 没有被编辑器加上 XML 声明或命名空间。用记事本打开，第一行应该是 <local:MyHint 或 <local:MyCard 之类，而不是 <?xml version="1.0">。

文字压在卡片标题上

给内容容器补上边距：Margin="12,40,12,14"。若启动器字号偏大，改成 44 或 48。

刷新了但内容没变化

按顺序检查：① 更新数据.bat 窗口是否提示成功（报错多为没装 Python 3 或未加入 PATH）；② 输出的 Custom.xaml 修改时间是否是刚刚；③ 启动器里是否点了"刷新主页"；④ 是否存在两个 Custom.xaml（见双位置同步）。

脚本提示找不到 Python

安装 Python 3（官网版或商店版均可），勾选"Add Python to PATH"。脚本会依次尝试 python 与 py -3，两者都不可用时才会失败。

网络原因导致抓取失败

用 --offline <dir> 指向本地缓存目录再生成；或等网络恢复后重跑。脚本不会把失败结果写进 Custom.xaml。

卸载与回退

在 Windows"设置 → 应用"里找到 PCL CE 自定义主页 卸载，或运行安装目录下的 unins000.exe。

卸载不会清空目录：只移除安装程序放入的四个文件，你后来添加的截图、笔记、备份都会保留。若想彻底清理，卸载后手动删除剩余目录即可。

想回退到启动器原版主页：在 PCL 设置里把主页恢复为官方/默认，或把"使用自定义主页"选项关闭，重启启动器即可，与卸载无关。
