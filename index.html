Features

它不是截图，是能点的真主页

所有内容由脚本生成到 Custom.xaml，PCL 直接加载，交互走启动器原生事件。

官方数据直连

版本清单取自 launchermeta，新闻与补丁日志取自 launchercontent，与官方启动器同源，不是二手搬运。

一键刷新不重启

跑一次 更新数据.bat（这一步需要本机 Python 3），再点主页上的"刷新主页"按钮，内容立刻换成最新，无需退出启动器。

零占位态

字段缺失就回退官方原文或整条跳过，绝不出现"翻译施工中"，版面不会因为缺数据而塌掉。

跟随启动器配色

颜色走 {DynamicResource ColorBrush1/4/5}，换主题、换强调色，主页自动跟着变。

符合 PCL XAML 规范

内嵌片段、无 XML 声明、无命名空间前缀，交互全部用启动器事件而非 WPF Click；PCL 侧不需要任何第三方库或组件。

双位置自动同步

一次生成同时写入桌面工程目录与 PCL 实际加载目录，维护端与运行端永不错位。

Quick start

三步让主页换新

1

安装到默认路径

双击安装包，选择语言后一路下一步，路径保持默认 D:\pcl主页 即可。

2

把 Custom.xaml 交给启动器

在 PCL 中打开 设置 → 个性化 → 主页，把主页文件指向安装目录下的 Custom.xaml。

3

刷新数据

双击目录里的 更新数据.bat 抓取最新官方数据，回到主页点"刷新主页"即生效。

cd /d "D:\pcl主页"

更新方式

只有一条路径：双击 更新数据.bat 跑一次，脚本重新抓取官方数据并覆写 Custom.xaml，再回主页点「刷新主页」即生效。

双击 更新数据.bat 跑一次

脚本自动探测解释器（python 或 py -3），抓完数据后同时写入工程目录与启动器实际加载目录，两个位置一次同步。

  • 不用记命令，跑一次就好
  • 无需退出启动器，点「刷新主页」即生效
  • 需要本机装好 Python 3（只用标准库，无需 pip 装包）

FAQ

常见问题

主页文字和卡片标题叠在一起怎么办？

MyCard 的标题栏是浮在内容之上的，内容容器的第一个元素必须留出上边距。默认用 Margin="12,40,12,14"；如果启动器字号或系统缩放更大，把 40 调成 44 或 48。

点按钮没反应 / 跳错地方？

交互必须成对使用 EventType 与 EventData：打开网页用 EventType="打开网页" + URL；跳启动器内部页用 EventType="切换页面" + EventData="Download|DownloadInstall" 这类枚举值，不能拿"打开网页"去跳内部页。

刷新后内容没变？

先确认 更新数据.bat 是否真的跑完（窗口里应出现生成成功提示），再回主页点"刷新主页"。若脚本报错，多半是没装 Python 3 或未加入 PATH——生成器依赖 Python 3 运行时（只用标准库，无需 pip 装包），装好后重试。注意只有"刷新数据"这一步需要 Python，启动器加载主页本身零依赖、不联网。

安装时能不能只给自己装？

可以。安装向导会先问"为所有用户安装 / 仅为我安装"。选前者会请求管理员权限，快捷方式落到公共目录；选后者只写入当前用户配置，不需要提权。

卸载会删掉我自己放进目录的文件吗？

不会。卸载程序只移除它自己安装的文件，不会清空整个目录，你后来放进去的内容会保留。
